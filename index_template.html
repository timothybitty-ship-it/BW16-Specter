Core Functionality & Features

Engineered specifically for the Realtek AmebaD RTL8720DN architecture.

Dual-Band 2.4GHz & 5GHz Deauther

Full 802.11a/b/g/n packet injection support across both 2.4GHz and 5GHz frequencies. Target individual access points or specific client devices with raw deauth frames.

Autonomous Sniffy AI Engine

Non-blocking single-scan sequential targeting mode. Automatically scans the spectrum, prioritizes strongest APs, initiates deauth bursts, and captures WPA/WPA2 handshakes without manual intervention.

ST7735 Cyberpunk Graphical UI

Full 128x160 TFT display driver featuring an animated bitmap state machine, real-time RF waterfall spectrum analyzer, RSSI target sorting, and zero-flicker double-buffered updates.

WPA/WPA2 Handshake Capture

Real-time EAPOL 4-way handshake detection and validation. Captured handshakes are stored in RAM and downloadable in standard .pcap format for hashcat/john analysis.

Captive Portal Phishing

Host customizable responsive captive portals with DNS redirection and concurrent deauth enforcement to test client authentication resilience.

REST API & Remote Web UI

Integrated SoftAP web server broadcasting on 192.168.4.1. Full mobile/desktop web dashboard for remote execution, live logs, and configuration.

ST7735 SPI Display Pinout

Display Signal BW16 Pin Type

TFT_DC (Data/Cmd) PA25 Control
TFT_RST (Reset) PA26 Control
TFT_SCLK (Clock) PA14 SPI CLK
TFT_MOSI (Data) PA12 SPI MOSI
TFT_BLK (Backlight) PA30 3.3V Control
VCC 3.3V Power
GND GND Ground

Navigation Button Controls

Button BW16 Pin Action
UP Button PB1 Move selection UP / Navigate back
OK / SELECT PB3 Short Press: Toggle / Select
Hold (Long Press): Return to Main Menu
DOWN Button PB2 Move selection DOWN / Navigate next
💡 Button Wiring Note: All buttons use internal INPUT_PULLUP resistors. Wire one side of each tactile switch to the respective BW16 pin and the other side to GND.
